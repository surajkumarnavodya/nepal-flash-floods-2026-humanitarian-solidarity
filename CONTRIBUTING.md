# Contributing

Contributions are welcome when they preserve the purpose and dignity of the project.

Please keep changes:
- humanitarian and human-centred
- factual and responsibly sourced
- accessible
- responsive
- lightweight
- free from sensational disaster imagery

Do not add fabricated statistics, emergency numbers, unverified donation claims, tracking scripts, or graphic imagery.

Before opening a pull request, test:
- desktop and mobile navigation
- hero carousel
- reduced-motion behavior
- external links
- local/static hosting
- GitHub Pages deployment
